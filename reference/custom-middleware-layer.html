自定义 MiddlewareLayer

impl MiddlewareLayer for AdminHeader {
    fn name(&self) -> &'static str { "admin_header" }
    fn is_enabled(&self) -> bool { self.enable }
    fn config(&self) -> serde_json::Result<Value> { serde_json::to_value(self) }
    fn apply(&self, app: AXRouter<AppContext>) -> Result<AXRouter<AppContext>> {
        Ok(app.layer(axum::middleware::map_response(add_header)))
    }
}

注册：default_middleware_stack(ctx) → push(Box::new(AdminHeader { enable: true })) → Hooks::middlewares 返回。

选择：map_response 适合只处理响应；需要检查请求并决定是否继续时，使用 from_fn。
