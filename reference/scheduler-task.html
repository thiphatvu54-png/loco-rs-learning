Scheduler + Task 速查

需求选择
人工一次性操作Task + cargo loco task
请求触发慢工作BackgroundWorker + perform_later
每天/每小时重复运行Scheduler 调用已注册 Task

命令

cargo loco task
cargo loco generate scheduler
cargo loco scheduler --config config/scheduler.yaml --list
cargo loco scheduler --config config/scheduler.yaml --name daily_report

配置

output: stdout
jobs:
  daily_report:
    run: "daily_report"
    schedule: "at 9:00 am"
    run_on_start: false

英文 schedule 避免误读 Cron；Cron 按秒、分、时、日、月、周、年排列。
