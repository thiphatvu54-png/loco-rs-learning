Loco 速查 · 目录 · 第 11 课

配置与环境速查

变量作用
LOCO_ENV选择 development / test / production
LOCO_CONFIG_FOLDER覆盖 config 文件夹路径
JWT_SECRET生产 JWT 签名密钥
DATABASE_URL数据库连接地址

PowerShell

$env:LOCO_ENV = "test"
cargo loco doctor
Remove-Item Env:LOCO_ENV

模板

secret: <%= get_env(name="JWT_SECRET") %>
port: <%= get_env(name="PORT", default="5150") %>

生产秘密不写入仓库，也不提供开发默认值；缺失时让启动失败。
