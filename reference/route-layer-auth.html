Routes::layer 与 JWT extractor

Routes::layer(...)       // 路由组级：日志、超时、限流、响应头
auth::JWT                // handler 级：验证 token，拿 claims
auth::JWTWithUser<User>   // handler 级：验证 token + 查用户
问题选择
所有 admin 路由都要超时.add(...).layer(timeout)
当前用户能否操作资源JWTWithUser + 业务授权规则
所有应用路由启用 CORSserver.middlewares

顺序：先 add 路由，再调用 layer。自定义 layer 中，next.run(req).await 之前是进入 handler 前，之后是响应返回后。
