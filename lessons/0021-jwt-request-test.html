JWT 路由请求测试：先证明 401，再证明 200

目标：用一个请求测试锁住认证边界，确保没有 token 进不了 handler，有效 token 才能进入业务代码。

1. 最小的匿名请求测试

use admin_api::app::App;
use loco_rs::testing::prelude::*;
use serial_test::serial;

#[tokio::test]
#[serial]
async fn list_without_token_is_401() {
    request::<App, _, _>(|request, _ctx| async move {
        let response = request.get("/api/categories").await;

        assert_eq!(response.status_code(), 401);
        let body: serde_json::Value = response.json();
        assert_eq!(body["error"], "unauthorized");
    })
    .await;
}

没有 token 时，JWT / JWTWithUser extractor 在 handler 之前拒绝请求，所以业务 handler 不会执行，预期是 401。

2. 再测一个成功分支

#[tokio::test]
#[serial]
async fn list_with_token_is_200() {
    request::<App, _, _>(|request, ctx| async move {
        let user = prepare_data::init_user_login(&request, &ctx).await;
        let (key, value) = prepare_data::auth_header(&user.token);

        let response = request
            .get("/api/categories")
            .add_header(key, value)
            .await;

        assert_eq!(response.status_code(), 200);
    })
    .await;
}

这里的测试结构是 Arrange → Act → Assert：准备测试用户和 token，发 HTTP 请求，断言状态码和响应体。
